# Ecology Tree Service

Marketing website for Ecology Tree Service, Inc. in Mount Kisco, New York.

## Local development

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
```

The static site is written to `dist/` for deployment to Cloudflare Pages.
